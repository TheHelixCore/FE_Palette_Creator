# FE Palette Creator

A browser-based palette editor for recoloring Fire Emblem 8 class battle sprites.

Pick a class, edit its 16-color palette (color pickers or click-to-eyedrop directly on the sprite), and watch the sprite recolor live. Colors snap to the GBA's real 5-bit-per-channel precision, so what you see is exactly what will ship in-game.

When you're happy with a palette, hit **Download Palette** and send the resulting JSON file back (or paste the hex codes shown into the shared sheet).

No install, no account -- just open the page.
